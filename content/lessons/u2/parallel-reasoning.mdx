## The stem and the task

*"The pattern of reasoning in which one of the following is most similar to that in the argument above?"*

Five arguments on five topics; one shares the original's logical skeleton. Topic similarity is a trap, sentence order is irrelevant, and the credited answer is often the longest and ugliest. The method is abstraction: strip the content until only form remains, then compare forms, conclusion first.

## The abstraction alphabet

| Words | Form |
|---|---|
| all, every, any, whenever | A → B |
| no, none | A → not B |
| only if, requires, unless (if not) | necessary condition: B ← A |
| some | A some B |
| most | A most B |
| probably, likely | hedged conclusion |
| should, ought | normative conclusion |

## What the right answer looks like

- Same **conclusion type** on all four axes: quantifier, polarity, certainty, mode.
- Same **premise structure**: count, kind, and the way they connect (chain, shared term, disjunction).
- Same **validity**. If the original is valid, a flawed copy is out even when every other feature matches, and vice versa: a Parallel Reasoning stimulus can itself be flawed, and then the match must share the flaw.
- Topic, order, length, and grammatical form (conditional vs categorical sentences) are **noise**.

## The level-4 version

- **Hidden contrapositives.** "No one who missed the retreat has the handbook" is H → attended. The skeleton is the same chain, written backwards. Translate before you compare.
- **Conditional conclusions.** The original concludes "if X then Z" rather than "every X is Z." Same form; different grammar. Don't let surface mode fool the filter.
- **Non-chain valid forms.** Disjunctive syllogism (A or B; not A; so B), or a chain with a "most" link (A most B, B → C, ∴ A most C). The choices will include a two-universal chain as bait.
- **Flawed originals.** Parallel Reasoning stems sometimes sit on an invalid argument. Don't assume validity; diagram and see.

<KeyIdea>
Parallel is matched on skeleton. Write the original in arrows and quantifiers, match the conclusion's type first (quantifier, polarity, certainty, mode), then the premise structure. Topic, order, and length are noise; one reversed arrow is not.
</KeyIdea>

## Before you read the choices

1. Type the conclusion on four axes.
2. Write the premises in the alphabet; note the connection.
3. Plan the two-pass elimination: conclusion filter, then structure.
