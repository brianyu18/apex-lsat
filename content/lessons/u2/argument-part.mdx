## The stem and the task

*"The claim that [X] plays which one of the following roles in the argument?"*

You are asked about one quoted claim. The answers describe roles in abstract language: *evidence offered in support of*, *an intermediate conclusion*, *a position the argument is directed against*. The task is to label the claim yourself first, then translate each choice and see which one says what you said.

## The decoder: answer language → role

| Answer language | Supported? | Supports? | Role |
|---|---|---|---|
| "evidence offered in support of the main conclusion" | No | Yes → MC | premise |
| "an intermediate conclusion that in turn supports…" | Yes | Yes | sub-conclusion |
| "the overall conclusion" / "the position the argument defends" | Yes | No | main conclusion |
| "a position the argument as a whole is directed against" | No | No | opposing view |
| "a consideration the argument acknowledges but discounts" | No | No | concession |
| "a general principle from which the conclusion is derived" | No | Yes → MC | premise (rule) |
| "an example offered to illustrate a general claim" | No | Yes → a premise | supporting premise |

## What the right answer looks like

- It gets **both** questions right and, when it names a target ("supports the claim that…"), the target is the claim the quoted sentence actually feeds.
- It describes a **relation**, not content. The best choices could be true of a thousand arguments.
- It attributes the claim to the right **holder**: the author, or the opponent.

## The level-4 version

- **Two-layer arguments.** The quoted claim supports a sub-conclusion, which supports the main conclusion. The credited answer says "supports a claim that is itself offered as support for the main conclusion." The trap says "supports the main conclusion." One target word decides.
- **The same claim, two holders.** The opponent states it as a premise; the author grants it as a concession. The role is fixed by how the *author* uses it.
- **Fully abstract choices.** "A phenomenon the argument offers a hypothesis to explain" versus "a hypothesis the argument offers to explain a phenomenon." Decode direction: which one is explained, which one explains.

<KeyIdea>
Two questions fix any sentence's role: Is it supported? Does it support, and what? Answer both from the text, then translate each choice into those two answers plus a target. A choice that misses on any one cell is wrong.
</KeyIdea>

## Before you read the choices

1. Mark the main conclusion.
2. For the quoted claim, write supported?/supports?/target.
3. Note the holder: author's claim, or the opponent's.
