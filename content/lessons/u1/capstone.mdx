## Four questions

Read every LR stimulus asking, in order:

<Steps>
1. **What's the conclusion?** (Or: is there one? If not, this is a Must Be True / MSS / Explain task.)
2. **What's offered for it?** Premises, sub-conclusions; set aside context and concessions.
3. **Where's the gap?** New term in the conclusion; leap in strength; a causal or conditional move; a sample standing in for a population.
4. **What would close or widen it?** The assumption, the weakener, the strengthener — all the same gap seen from different sides.
</Steps>

If you do these four before reading the stem, the stem just tells you which side of the gap to report.

## Run it once, end to end

    { text: "Satisfied employees are less likely to leave.", role: "premise", why: "A second premise linking satisfaction to retention." },
    { text: "Some managers worry that remote work erodes team cohesion.", role: "context", why: "An opposing concern, acknowledged and then set aside — the argument never uses it." },
    { text: "Companies seeking to reduce turnover should therefore allow at least two remote days a week.", role: "conclusion", why: "The recommendation everything else is meant to justify." }
  ]}
/>

**Step 3 — the gaps.** Two of them:

- *Correlation → causation.* Remote work and satisfaction go together; maybe satisfied (trusted, senior) employees are the ones allowed to work remotely. Reverse causation and alternative cause both live here.
- *Reported satisfaction → retention → policy.* "Report higher satisfaction" is self-report; "less likely to leave" is behavior; "should allow" is a recommendation that assumes no offsetting cost.

**Step 4 — the gap from each side.**

| Stem asks for | You'd expect |
|---|---|
| Flaw | "treats a correlation as evidence of causation" |
| Necessary assumption | "Employees allowed to work remotely are not disproportionately those who were already satisfied" |
| Weaken | "Remote-work privileges are typically granted to senior employees, who have low turnover regardless" |
| Strengthen | "When a firm extended remote days to all staff, turnover fell among previously office-bound employees" |
| Evaluate | "Were the remote-working employees more satisfied before they began working remotely?" |

Same gap, five answers.

<KeyIdea>
You are not learning fifteen question types. You are learning one read, and fifteen stems that ask you to report a different part of it.
</KeyIdea>

## What you should be able to do now

- State any argument's conclusion in your own words in under ten seconds.
- Classify a sentence's role with the two questions (*supported? supports?*).
- Translate a dense sentence into plain clauses without changing its force.
- Diagram any conditional from any indicator group, and take its contrapositive.
- Recognize which quantifier combinations chain and which don't.
- Name the flaw family of an argument before looking at the choices.
- List the three rivals to any causal claim.

If any of these is shaky, the lesson list for Unit 1 is one click back. Shaky foundations show up later as "logic gap" tags on hard questions — cheaper to fix now.
