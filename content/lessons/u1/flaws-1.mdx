## Flaws are shapes, not topics

A flawed argument has a gap of a recognizable kind. The test reuses the same dozen kinds across thousands of stimuli. Learn them as *shapes* and you'll see the gap before you finish reading.

| Family | Shape | Exposing question |
|---|---|---|
| **Correlation → causation** | A and B occur together, so A causes B | Could something else cause both? Could B cause A? Coincidence? |
| **Sampling** | This sample shows X, so the population does | Is the sample representative? Self-selected? Small? |
| **Part / whole** | Each part has X, so the whole does (or vice versa) | Does the property survive composition or division? |
| **Necessary / sufficient** | A requires B; B is present; so A | Is B merely required, or does it guarantee? |
| **Equivocation** | A word changes meaning mid-argument | Is "natural / free / value / success" used the same way twice? |
| **Appeal to authority / popularity** | Experts (or most people) believe X, so X | Is the authority relevant? Is popularity evidence? |
| **False dilemma** | Not A, so B | Are A and B really the only options? |
| **Percentage / number** | Share rose, so count rose | What happened to the total? |
| **Absence of evidence** | No proof of X, so not-X | Was anyone looking? Would evidence exist if X were true? |
| **Circular** | X, because X (restated) | Does the premise just restate the conclusion? |
| **Ad hominem** | The person is bad, so their claim is false | Does the source's character bear on the claim's truth? |
| **Straw man / mental state** | Attacks a distorted version; or infers reality from belief/intent | Is this what they said? Does believing make it so? |

Add two from earlier lessons: **relative → absolute** (grammar-3) and **conclusion stronger than premises** (arguments-2).

## The method

<Steps>
1. Find the conclusion; find the premises.
2. Say the gap in plain words: "goes from ___ to ___."
3. Match the gap to a family.
4. Read the choices looking for *that* family in abstract words. Reject answers that describe a different gap, attack a premise, or raise a practical objection.
</Steps>

<KeyIdea>
A Flaw answer must describe something the argument *actually did*. "Fails to consider X" is correct only if considering X would matter to this conclusion. The most tempting wrong answers describe real flaws that this argument didn't commit.
</KeyIdea>
