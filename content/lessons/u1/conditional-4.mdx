## The errors

Given a rule **A → B**, an argument that makes any of these moves is invalid:

| Error | Argument does | Looks like |
|---|---|---|
| **Affirming the necessary** | B is true, so A is true | "Cancelled matches follow rain; the match was cancelled, so it rained." |
| **Denying the sufficient** | A is false, so B is false | "It didn't rain, so the match wasn't cancelled." |
| **Reversal** | states B → A as if it were A → B | "Since all experts are careful, careful people must be experts." |
| **Necessary ≠ sufficient** | treats a requirement as a guarantee | "A degree is required for the job, so with a degree she'll get it." |

The last two are the same mistake described from different ends. The LSAT describes all four in abstract language — recognizing the description is the skill.

## How the answers phrase it

- *"takes a condition that is necessary for X to be a condition that is sufficient for X"*
- *"confuses a sufficient condition with a necessary one"*
- *"infers that something is true of the whole because of a condition that merely guarantees it is possible"*
- *"concludes that an outcome will not occur merely because one way of bringing it about is absent"* — denying the sufficient
- *"treats the fact that a result occurred as evidence that a particular cause occurred"* — affirming the necessary, often with causal dressing
- *"mistakes a claim that something is required for a claim that it is enough"*

<KeyIdea>
Translate the abstract answer back into arrows, then check the argument's arrows. If the answer says the argument "treated necessary as sufficient," find the rule, find which side the argument started from, and confirm it started from the wrong one.
</KeyIdea>

## Parallel Flaw: matching the shape

Parallel Flaw questions ask you to find another argument with the *same* error. Reduce both to arrows:

> Stimulus: "Successful startups all have strong founders. This startup has strong founders, so it will succeed." — **affirming the necessary** (success → strong founders; strong founders ∴ success).

Now scan choices for the same shape, ignoring topic:

- *"All dolphins are mammals. This animal is a mammal, so it's a dolphin."* — same shape. ✓
- *"All dolphins are mammals. This animal is not a mammal, so it's not a dolphin."* — valid contrapositive. ✗
- *"All dolphins are mammals. This animal is not a dolphin, so it's not a mammal."* — denying the sufficient. Wrong flaw. ✗

Topic similarity is the trap: the choice about startups is almost never the answer.
